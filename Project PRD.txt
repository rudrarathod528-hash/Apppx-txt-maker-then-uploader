============================================================
                 PRD — APPX COURSE BOT
              IMPROVED TELEGRAM-FIRST v2.0
============================================================

PRODUCT TYPE:
Telegram-based Authorized Course Management & Media Processing Bot

PRIMARY OBJECTIVE:
User apne authorized course account ko Telegram ke through login kare,
available courses dekhe, course ka complete content list generate kare,
TXT file Telegram par receive kare, aur authorized/officially accessible
media ko optionally process karke Telegram par receive kar sake.

CORE PRINCIPLE:

Telegram is the complete user interface.

User ko website/admin panel par jaane ki zarurat nahi honi chahiye.

Telegram
   ↓
Login
   ↓
Account
   ↓
Courses
   ↓
Course Content
   ↓
TXT Export
   ↓
Optional Media Job
   ↓
Telegram Delivery

13. MEDIA PROCESSING
============================================================

Only authorized/officially accessible media may be processed.

Flow:

Selected Content
      ↓
Check authenticated access
      ↓
Resolve platform-provided media resource
      ↓
Download/process using permitted method
      ↓
Temporary file
      ↓
Telegram upload
      ↓
Delete temporary file


Supported examples:

- Direct downloadable media
- Platform-provided downloadable resources
- HLS/DASH when access and processing are officially permitted
- PDF
- Other supported media formats


DRM:

If content is DRM-protected and no official permitted download/export
method is available:

DO NOT attempt to bypass DRM.

Instead:

❌ Media cannot be processed through the available authorized method.

============================================================

1000+
5000+ items

For TXT:

Stream generation where practical.

Process one item at a time.

Item
 ↓

 ↓

 ↓

 ↓

============================================================
